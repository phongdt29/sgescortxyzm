Custom theme for Singapore Escort Hub. Front page landing, Services/Models/FAQ from CPT, footer widgets, menu from Admin.

== Description ==

* Front page: Hero, About, Services, Counter, Portfolio, Banner, Team, Testimonials, FAQ, News.
* Custom Post Types: Services, Models, FAQs (manage in WP Admin).
* Primary menu (Appearance > Menus) + footer widget areas.
* Templates: front-page, page, single, index, archive, search, 404, sidebar, comments.

== Installation ==

1. Upload the theme folder to wp-content/themes/
2. Activate the theme in Appearance > Themes.
3. Set Reading: Your homepage displays = A static page, and choose your front page.
4. Optional: Create a menu and assign to Primary Menu; add widgets to Footer and Sidebar.
